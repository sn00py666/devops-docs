# Журнал типовых инцидентов

| Инцидент | Наблюдаемый признак | Первичный источник диагностики |
|---|---|---|
| Неиспользуемая переменная | Красная проверка `pylint` в PR | Шаг Static analysis |
| Недостаточные права публикации | `build` успешен, `deploy` не получает OIDC-токен | Журнал deploy-pages и блок permissions |
| Битая ссылка | `mkdocs build --strict` завершается ошибкой | Шаг Build documentation |
| Старая версия после успешного деплоя | Прежнее содержимое в браузере | URL окружения, время публикации, кэш браузера |
